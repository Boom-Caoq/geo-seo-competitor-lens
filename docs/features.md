# 功能性说明

## 定位

**竞对透视 · GEO×SEO** 是给 Cursor / Agent 用的可复用 Skill（提示词与流程规范），不是托管 SaaS。

它把「找竞对 → SEO 外链 → AI 引用来源 → 打分 → 优化清单」固化成同一套输出，减少每次从零提问。

## 核心模块

### 1. 竞对识别

- 站点自述（title / H1 / about / 产品词）
- 搜索引擎核心词 SERP
- 同类工具 / 内容 / SaaS 落地页
- 输出：名称、URL、入选理由、关键词重叠度
- 默认锁定 3–5 个主竞对

### 2. SEO 外链与权威信号

对目标站 + 每个竞对尽量收集：

- 外链域名数量级与类型分布（媒体 / 博客 / 目录 / 社交 / UGC）
- 锚文本与落地页倾向（品牌锚 vs 关键词锚；首页 vs 内容页）
- 易获链内容资产（教程、数据报告、工具页、对比页）
- 技术可见性（sitemap、robots、索引、hreflang）

约束：无付费 SEO 账号时只用公开可验证线索；禁止假装已接 Ahrefs / Semrush。

### 3. GEO（生成式引擎优化）可见性

对同一组问题（品牌 / 品类 / 对比 /「最佳·怎么选」）：

- 记录各模型或带引用产品是否出现目标站 / 竞对
- 记录实际被引用的域名与类型（官网 / 媒体 / 社区 / 文档）
- 归纳「谁在喂养模型」

### 4. 评分卡（0–100）

默认权重（可在报告中声明微调）：

| 维度 | 权重 |
| --- | --- |
| 内容可引用性 | 25 |
| 外链与提及 | 25 |
| 技术与可抓取 | 15 |
| 关键词与意图覆盖 | 15 |
| GEO 可见性 | 20 |

输出目标站与竞对总分，并写强项 / 弱项。

### 5. 对比结论

短表对比各维度差距；点明：

- 1 个「最大被拉开的口子」
- 1 个「你已领先可加码」的点

### 6. 优化方案

分 30 天 / 90 天，覆盖内容、外链、技术、GEO。  
每条建议包含：动作 | 影响维度 | 优先级 P0/P1/P2 | 验收标准。  
明确禁止买卖垃圾外链与刷量。

## 边界与合规

- 不编造数据；查不到标「未验证 / 无公开数据」
- 白帽建议 only
- 适合独立站 / SaaS / 内容站 / 出海工具；不适合黑帽诉求

## 与「源码」的关系

本仓库的「源码」即 `skills/geo-seo/SKILL.md`：Agent 按该文件执行。  
无单独运行时服务；能力取决于你使用的 Agent 能否访问网页与搜索。
