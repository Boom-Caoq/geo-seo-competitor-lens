# 使用教程

## 1. 安装 Skill

本 Skill 是一个含 `SKILL.md` 的文件夹，路径：

```text
skills/geo-seo/SKILL.md
```

### Cursor

1. Clone 本仓库，或下载 ZIP 后解压。
2. 将 `skills/geo-seo` 复制到 Cursor / Grok Bot 等产品的 Skills（或 workflows）目录。
3. 确认 Agent 能加载名为「竞对透视 · GEO×SEO」或 id `geo-seo` 的 skill。

### 上传安装

若产品支持「上传 Skill 文件夹」：

- 选择 `skills/geo-seo/`（内含 `SKILL.md`）
- 注意常见限制：单文件 ≤10MB，总包 ≤30MB（本 Skill 远小于此）

### 校验安装

对新对话说：

```text
你有哪些 skill？有没有「竞对透视」或 geo-seo？
```

能列出即可。

## 2. 第一次跑通

最少命令：

```text
分析 https://你的网站.com
```

推荐带上下文：

```text
用竞对透视 · GEO×SEO 分析 https://你的网站.com
行业：加密工具站
语言：中文为主，英文也看
对标数量：5
重点看：Perplexity / AI Overview 是否引用我们
```

## 3. 读报告的顺序

1. **一句话总评 + 总分** — 先判断整体落差  
2. **竞对表** — 确认对标对象是否合理；不对就让 Agent 换一批  
3. **外链对比** — 看域名类型差距，而不是只看数量  
4. **AI 引用表** — 看「谁在喂模型」  
5. **评分卡** — 找最低分维度  
6. **30/90 天清单** — 只执行 P0，再排 P1  
7. **数据缺口** — 无 Ahrefs 等付费数据时，别把「未验证」当结论

## 4. 常见追问

```text
把竞对换成 A、B、C 三个站再打一次分
只输出 GEO 引用表和 30 天内容清单
用英文再出一版交付
把优化清单改成可直接贴进 Notion 的表格
```

## 5. 多站点 / 批量

一次只分析一个主站最稳。多个站请分多次调用，或明确：

```text
依次分析下列站点，每个站点单独一份报告：…
```

## 6. 故障排查

| 现象 | 处理 |
| --- | --- |
| Agent 没走完整 7 段结构 | 明确说「严格按 SKILL.md 第 7 节交付格式」 |
| 编造了外链数字 | 要求「只保留可验证来源，其余标未验证」 |
| 竞对全是巨头平台 | 补充「去掉目录站与平台巨头，只留同类产品站」 |
| GEO 全空 | 换可访问的带引用产品，或接受数据缺口并先做 SEO 段 |
